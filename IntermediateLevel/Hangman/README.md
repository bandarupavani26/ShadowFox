## Project Description

This project is a simple command-line Hangman game developed using Python. The player has to guess the hidden word one letter at a time within a limited number of attempts. The game displays the current progress after each guess and informs the player whether they have won or lost.

---

## Features

- Random word selection
- Letter-by-letter guessing
- Limited number of attempts
- Input validation
- Win/Loss message
- User-friendly console interface
